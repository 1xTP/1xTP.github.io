### Overview
ARGUS is a Python tool that automates the first phase of enumeration against a target. Give it an IP address and a domain, and it runs port discovery, finds virtual hosts, fingerprints the web applications it finds, and fuzzes directories, printing everything as one readable stream.

It wraps Nmap, ffuf, and WhatWeb in an object-oriented pipeline. Each tool lives in its own module, and every module reads from and writes to a single shared `Target` object. I built it for authorized CTF environments like Hack The Box, and it is the project whose design I'm most proud of, so this writeup focuses on the structure.

### The Problem
The first ten minutes against a new target are repetitive:

1. Run a port scan and wait for service enumeration.
2. Map the IP and domain in `/etc/hosts` by hand.
3. Look for virtual hosts or subdomains, then edit `/etc/hosts` again so they resolve.
4. Start fuzzing directories without knowing what is running behind each port, and lose time to slow backends and wildcard redirects.

I wanted one command that does all of this in the right order. My first version did, but it was a monolithic class that scraped text output from several tools (Dirsearch included) and used temporary files to edit `/etc/hosts`. ARGUS is the rewrite: decoupled classes, fast compiled tools, machine-readable output wherever possible, and explicit error handling.

### How It Runs
The pipeline in `main` runs six steps in a fixed order:

1. `HostsManager` maps the base domain to the target IP.
2. `PortScanner` finds open ports and identifies their services.
3. `FfufScanner` fuzzes for virtual hosts on the web ports.
4. `HostsManager` runs again so the new subdomains resolve.
5. `WebScanner` fingerprints every discovered URL.
6. `FfufScanner` fuzzes directories on each URL.

Every step stores its results on the `Target`, so later steps pick up earlier findings without any scanner knowing about another.

### Architecture

| Class | Wraps | Responsibility |
|---|---|---|
| `Target` | n/a | Shared state and URL generation |
| `BaseScanner` | n/a | Parent class for every external-tool module |
| `PortScanner` | Nmap | Two-stage port and service discovery |
| `FfufScanner` | ffuf | Virtual host discovery and directory fuzzing |
| `WebScanner` | WhatWeb | Web application fingerprinting |
| `HostsManager` | `/etc/hosts` | Keeps local name resolution in sync with findings |

**`Target`: one source of truth.**
All target metadata lives in one object: IP, domain, wordlists, open ports (with service, version, and SSL flag), subdomains, the ports that responded to virtual host routing (`vhost_ports`), directory hits, and web application fingerprints. Nothing is duplicated across scanners.

`Target.get_urls()` turns that state into candidate URLs. It keeps only HTTP services (by service name or well-known web port), picks the right scheme, and drops default ports from the URL. It only pairs a subdomain with a port that actually answered virtual host routing, which avoids testing every subdomain against every web port.

**`BaseScanner`: the contract every module follows.**
- **Dependency check:** the constructor verifies the binary exists in `$PATH` with `shutil.which()` and exits with a clear message if it doesn't.
- **Two execution modes:** `execute()` runs a tool to completion and returns its output (Nmap, WhatWeb). `execute_stream()` is a generator that yields output line by line (ffuf), so hits print as they arrive, and the subprocess is always terminated and cleaned up on exit.
- **Interrupt handling:** one `Ctrl+C` skips the scan currently running, and a second within 1.5 seconds quits the whole program. A slow scan on one host doesn't force a full restart.

Adding a new tool means subclassing `BaseScanner`, setting `binary`, reading from and writing to `Target`, and adding one line to the pipeline. No existing class has to change.

### Design Decisions

**Two-stage port scan.**
Running full service enumeration across all 65,535 ports in one command is slow and drops packets over a VPN. `PortScanner` first runs a fast SYN sweep (`-sS -p- --min-rate 5000`), then runs a service scan (`-sCV`) only against the ports that came back open. Both stages request XML output (`-oX -`), and one shared helper, `_get_open_ports()`, parses it with `xml.etree.ElementTree` instead of regexes over text.

**Identify the application, not just the web server.**
Knowing a port runs `nginx` or `Apache` says little about what is behind it. `WebScanner` runs WhatWeb with JSON output (`--log-json=-`) and reads specific fields: page title, server header, `X-Powered-By`, generator tags, session cookies (such as `PHPSESSID` or `laravel_session`), uncommon headers, and the final URL after any redirects. Reading structured fields is more reliable than version-scraping regexes that break between releases. This step runs before directory fuzzing, so the technology stack is on screen before the fuzzing output starts.

**Structured output and wildcard protection with ffuf.**
Directory fuzzing runs with `-s -json`, so each hit arrives as one JSON line that ARGUS parses as it streams in, capturing status code, response size, word count, and redirect target. Virtual host discovery uses silent mode, where each output line is a hit. Wildcard and catch-all routes, which are common in modern frameworks, can send recursive fuzzing into huge queues, so ARGUS combines auto-calibration (`-ac`), a recursion depth of 2, and a hard per-job time cap (`-maxtime-job 60`).

**Safe `/etc/hosts` updates.**
`HostsManager` compares the file against the target domain and any discovered subdomains, shows what is missing or stale, and asks for confirmation before changing anything. The new file contents are built in memory and piped into `sudo tee /etc/hosts`, so there are no temporary files to clean up, and the existing file's ownership and permissions are untouched. Old entries for those hostnames that point at a different IP are removed rather than left behind.

**Fail early, fail clearly.**
A missing binary or wordlist stops the program at startup with a specific message. A failed subprocess or unparseable Nmap and WhatWeb output is reported and skipped instead of crashing the run.

### Usage

**Prerequisites**
These must be installed and available in your `$PATH`:
- `nmap`
- `ffuf`
- `whatweb`
- SecLists wordlists

The SYN scan and the `/etc/hosts` update both call `sudo`, so expect a password prompt.

**Execution**
```bash
# Standard run using default SecLists paths
./argus.py -i 10.10.10.10 -d target.htb

# Custom wordlist paths
./argus.py -i 10.10.10.10 -d target.htb -sw /path/to/subdomains.txt -dw /path/to/directories.txt
```

### Responsible Use
ARGUS generates aggressive scan and fuzzing traffic. It is intended only for systems you own or are explicitly authorized to test, such as CTF platforms, home labs, and in-scope engagements.

### Source Code

```python
#!/usr/bin/env python3
import argparse
import json
import os
import shutil
import subprocess
import sys
import time
import urllib.parse
import xml.etree.ElementTree as ET


class Target:
    WEB_PORTS = (80, 443, 3000, 5000, 8000, 8080, 8443, 8888)

    def __init__(self, ip, domain, sub_wordlist=None, dir_wordlist=None):
        self.ip = ip.strip()
        clean = domain.replace("http://", "").replace("https://", "")
        self.domain = clean.split("/")[0].split(":")[0].strip()

        self.sub_wordlist = sub_wordlist or "/usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-20000.txt"
        self.dir_wordlist = dir_wordlist or "/usr/share/wordlists/SecLists/Discovery/Web-Content/raft-medium-directories.txt"

        for wl in (self.sub_wordlist, self.dir_wordlist):
            if not os.path.isfile(wl):
                sys.exit(f"[!] Wordlist not found: '{wl}'")

        self.open_ports = {}
        self.subdomains = []
        self.vhost_ports = set()
        self.directories = {}
        self.web_apps = {}

    def get_urls(self, include_subdomains=True):
        urls = []

        for port, info in self.open_ports.items():
            service = info["service"].lower()
            is_http = "http" in service or port in self.WEB_PORTS
            if not is_http:
                continue

            is_ssl = info.get("ssl", False) or "https" in service or port in (443, 8443)
            scheme = "https" if is_ssl else "http"
            default_port = 443 if is_ssl else 80

            hosts = [self.domain]
            if include_subdomains and port in self.vhost_ports:
                hosts.extend(self.subdomains)

            for host in hosts:
                urls.append(f"{scheme}://{host}" if port == default_port else f"{scheme}://{host}:{port}")

        return urls


class HostsManager:
    hosts_path = "/etc/hosts"

    def __init__(self, target):
        self.target = target

    def _get_missing_domains(self):
        wanted = [self.target.domain] + self.target.subdomains
        active = set()

        with open(self.hosts_path, "r") as f:
            for line in f:
                parts = line.split("#")[0].split()
                if parts and parts[0] == self.target.ip:
                    active.update(parts[1:])

        return [d for d in wanted if d not in active]

    def sync(self):
        missing = self._get_missing_domains()
        if not missing:
            return

        print(f"[*] Missing or outdated in /etc/hosts: {', '.join(missing)}")
        try:
            if input("[?] Update /etc/hosts? [Y/n]: ").strip().lower() not in ("", "y"):
                return
        except EOFError:
            return

        wanted_set = set([self.target.domain] + self.target.subdomains)
        with open(self.hosts_path, "r") as f:
            lines = f.readlines()

        ip_found = False
        new_lines = []

        for line in lines:
            parts = line.split("#")[0].split()
            if not parts:
                new_lines.append(line)
                continue

            line_ip, line_domains = parts[0], parts[1:]
            if line_ip == self.target.ip and not ip_found:
                merged = list(dict.fromkeys(line_domains + missing))
                new_lines.append(f"{self.target.ip}\t{' '.join(merged)}\n")
                ip_found = True
            else:
                kept = [d for d in line_domains if d not in wanted_set]
                if kept:
                    new_lines.append(f"{line_ip}\t{' '.join(kept)}\n")

        if not ip_found:
            new_lines.append(f"{self.target.ip}\t{' '.join(missing)}\n")

        try:
            subprocess.run(
                ["sudo", "tee", self.hosts_path],
                input="".join(new_lines),
                text=True,
                stdout=subprocess.DEVNULL,
                check=True
            )
            print(f"\t[+] Updated /etc/hosts ({self.target.ip} -> {', '.join(missing)})")
        except subprocess.CalledProcessError as e:
            print(f"[!] Failed to update /etc/hosts: {e}")


class BaseScanner:
    binary = None
    _last_sigint = 0.0

    def __init__(self, target):
        self.target = target
        if self.binary and shutil.which(self.binary) is None:
            sys.exit(f"[!] Missing required binary '{self.binary}' in PATH.")

    def _handle_sigint(self, label):
        now = time.time()
        if now - BaseScanner._last_sigint < 1.5:
            raise KeyboardInterrupt
        BaseScanner._last_sigint = now
        print(f"\n[!] {label} skipped. (Press Ctrl+C again within 1.5s to quit Argus)")

    def execute(self, cmd):
        try:
            res = subprocess.run(cmd, capture_output=True, text=True, check=False)
            if res.returncode != 0 and not res.stdout.strip():
                print(f"[!] {cmd[0]} failed: {res.stderr.strip() or res.returncode}")
                return None
            return res.stdout
        except KeyboardInterrupt:
            self._handle_sigint(cmd[0])
            return None

    def execute_stream(self, cmd):
        proc = subprocess.Popen(cmd, stdout=subprocess.PIPE, stderr=subprocess.DEVNULL, text=True, bufsize=1)
        try:
            for line in proc.stdout:
                yield line
        except KeyboardInterrupt:
            proc.terminate()
            self._handle_sigint(cmd[0])
        finally:
            if proc.stdout:
                proc.stdout.close()
            try:
                proc.wait(timeout=2)
            except subprocess.TimeoutExpired:
                proc.kill()
                proc.wait()


class PortScanner(BaseScanner):
    binary = "nmap"

    def _get_open_ports(self, xml_data):
        if not xml_data:
            return []
        try:
            root = ET.fromstring(xml_data)
            return [
                p for p in root.findall(".//port")
                if p.find("state") is not None and p.find("state").get("state") == "open"
            ]
        except ET.ParseError:
            print("[!] Failed to parse Nmap XML output.")
            return []

    def scan(self):
        print(f"[*] Scanning all ports on {self.target.ip}...")
        fast_cmd = ["sudo", self.binary, "-sS", "-p-", "--min-rate", "5000", "-n", "-Pn", self.target.ip, "-oX", "-"]
        open_elements = self._get_open_ports(self.execute(fast_cmd))

        if not open_elements:
            print("[-] No open ports found.")
            return

        port_list = ",".join(p.get("portid") for p in open_elements)
        print(f"[*] Running service enumeration on ports: {port_list}...")
        ver_cmd = ["sudo", self.binary, "-sCV", "-Pn", "-p", port_list, self.target.ip, "-oX", "-"]

        for port in self._get_open_ports(self.execute(ver_cmd)):
            port_id = int(port.get("portid"))
            service = port.find("service")

            if service is not None:
                name = service.get("name", "unknown")
                full_ver = f"{service.get('product', '')} {service.get('version', '')}".strip()
                is_ssl = service.get("tunnel") == "ssl"
            else:
                name, full_ver, is_ssl = "unknown", "", False

            self.target.open_ports[port_id] = {"service": name, "version": full_ver, "ssl": is_ssl}
            ver_str = f" ({full_ver})" if full_ver else ""
            print(f"\t[+] {port_id}/tcp - {name}{ver_str}")


class FfufScanner(BaseScanner):
    binary = "ffuf"

    def scan_subdomains(self):
        urls = self.target.get_urls(include_subdomains=False)
        if not urls:
            print("[!] No HTTP(S) services found.")
            return

        for url in urls:
            parsed = urllib.parse.urlparse(url)
            port = parsed.port or (443 if parsed.scheme == "https" else 80)

            print(f"\n[*] Fuzzing subdomains on {url}...")
            cmd = [
                self.binary, "-w", self.target.sub_wordlist,
                "-u", url, "-H", f"Host: FUZZ.{parsed.netloc}",
                "-ac", "-s"
            ]

            for line in self.execute_stream(cmd):
                sub = line.strip()
                if sub:
                    full_domain = f"{sub}.{self.target.domain}"
                    self.target.vhost_ports.add(port)
                    if full_domain not in self.target.subdomains:
                        self.target.subdomains.append(full_domain)
                        print(f"\t[+] {full_domain}")

    def scan_directories(self):
        for url in self.target.get_urls(include_subdomains=True):
            print(f"\n[*] Fuzzing directories on {url} (depth: 2)...")
            self.target.directories[url] = []

            cmd = [
                self.binary, "-w", self.target.dir_wordlist,
                "-u", f"{url}/FUZZ", "-recursion", "-recursion-depth", "2",
                "-maxtime-job", "60", "-ac", "-s", "-json"
            ]

            for line in self.execute_stream(cmd):
                try:
                    data = json.loads(line)
                except json.JSONDecodeError:
                    continue

                hit_url = data.get("url", "")
                if not hit_url:
                    continue

                entry = {
                    "path": hit_url.replace(f"{url}/", "", 1),
                    "status": data.get("status"),
                    "length": data.get("length"),
                    "words": data.get("words"),
                    "redirect": data.get("redirectlocation", "")
                }
                self.target.directories[url].append(entry)

                meta = f"[Status: {entry['status']}, Size: {entry['length']}B, Words: {entry['words']}]"
                arrow = f" -> {entry['redirect']}" if entry["redirect"] else ""
                print(f"\t[+] {hit_url:<45} {meta}{arrow}")


class WebScanner(BaseScanner):
    binary = "whatweb"
    USER_AGENT = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/122.0.0.0 Safari/537.36"
    FIELDS = {
        "Title": ("Title",),
        "Server": ("HTTPServer", "Server"),
        "Powered-By": ("PoweredBy", "X-Powered-By"),
        "Generator": ("MetaGenerator", "Meta-Author"),
        "Cookies": ("Cookies",),
        "Headers": ("UncommonHeaders",),
    }

    def scan(self):
        urls = self.target.get_urls(include_subdomains=True)
        if not urls:
            return

        print("\n[*] Fingerprinting web applications...")
        for url in urls:
            self._fingerprint(url)

    def _fingerprint(self, url):
        cmd = [self.binary, "-a", "3", "-q", f"--user-agent={self.USER_AGENT}", "--log-json=-", url]
        raw_output = self.execute(cmd)
        if not raw_output or not raw_output.strip():
            return

        try:
            entries = [e for e in json.loads(raw_output) if e.get("plugins")]
        except json.JSONDecodeError:
            print(f"\t[!] Could not parse WhatWeb JSON for {url}")
            return

        if not entries:
            return

        final = entries[-1]
        plugins = final.get("plugins", {})
        status = final.get("http_status", "Unknown")
        final_url = final.get("target", url)

        header = f"{url} -> {final_url}" if final_url.rstrip("/") != url.rstrip("/") else url
        print(f"\t[+] {header} [{status}]")
        self.target.web_apps[url] = {"final_url": final_url, "status": status}

        for label, candidates in self.FIELDS.items():
            for name in candidates:
                p = plugins.get(name, {})
                raw = p.get("string", []) + p.get("version", []) + p.get("os", [])
                vals = list(dict.fromkeys(str(v) for v in raw if v != "--"))
                if vals:
                    val = ", ".join(vals)
                    self.target.web_apps[url][label.lower()] = val
                    print(f"\t    {label:<10} : {val}")
                    break


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="Argus OOP Recon")
    parser.add_argument("-i", "--ip", required=True, help="Target IP")
    parser.add_argument("-d", "--domain", required=True, help="Target Domain")
    parser.add_argument("-sw", "--sub-wordlist", help="Path to subdomain wordlist")
    parser.add_argument("-dw", "--dir-wordlist", help="Path to directory wordlist")
    args = parser.parse_args()

    try:
        target = Target(args.ip, args.domain, args.sub_wordlist, args.dir_wordlist)
        hosts = HostsManager(target)

        hosts.sync()
        PortScanner(target).scan()

        ffuf = FfufScanner(target)
        ffuf.scan_subdomains()

        hosts.sync()
        WebScanner(target).scan()
        ffuf.scan_directories()
    except KeyboardInterrupt:
        sys.exit("\n[!] Argus terminated by user.")
```
